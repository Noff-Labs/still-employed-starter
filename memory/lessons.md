# Lessons

Dated lessons, newest first: what worked, what failed, and the rule that comes
from it. Every agent reads this file before acting, so a mistake happens only
once. Other roles suggest lessons; the chief of staff writes them.

Write each lesson as a rule someone else could follow. Keep the story short and
the rule clear.

## Format

**YYYY-MM-DD: The rule, in one sentence.** What happened, in one or two
sentences. What to do from now on.

## Entries

**YYYY-MM-DD: Example: check the attachment before you summarize the email.**
A summary missed a changed date that was only in the attachment. From now on,
open every attachment before writing a summary.

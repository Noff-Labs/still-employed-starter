# Decisions

Dated decisions, newest first. One entry per decision: the date, what was
decided, and why. When a decision changes, add a new entry. Don't edit the old
one.

## Format

**YYYY-MM-DD: What was decided.** Why, in one or two sentences.

## Entries

**YYYY-MM-DD: Example: drafts for outside people always go to `output/` first.**
The reader wants to read every message before it is sent.

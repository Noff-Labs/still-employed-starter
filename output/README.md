# Output: drafts waiting for you

This is the staging folder. Everything an agent prepares for the reader lands
here as a dated file: `YYYY-MM-DD-<what-it-is>.md`. Draft emails, replies,
forms filled in but not submitted, comparisons with a recommendation, scripts
for a phone call.

That is the human gate: the system is set up to stage drafts here and never to
send, submit, publish, pay or book anything itself. The reader decides and
acts. AI can make mistakes, so it's a good idea to check a draft before you use
it.

When a draft has been used or rejected, write the decision in
`memory/decisions.md` if it matters. Then the draft can be deleted.

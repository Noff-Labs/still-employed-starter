# Knowledge

What the team should know about the reader's work or life: how things are
done, who is who (first names only), standing preferences, useful facts.

- One file per topic, for example `about.md`, `how-we-write-emails.md`,
  `suppliers.md`.
- The Guide creates `about.md` during setup.
- Follow `rules/privacy.md`. Facts, not identifiers.
- Write where a fact came from and when you checked it, if it can change.

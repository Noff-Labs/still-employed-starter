# Never-write list (example)
#
# Copy this file to never-write.txt in the same folder, then add your own
# entries below. Git ignores never-write.txt, so git doesn't save or upload
# it. Type the entries yourself in a text editor. Don't paste them into an AI
# chat.
#
# What the never-write list is for. Some details aren't secret, but you'd
# still rather they never end up in your files, where they could be copied or
# shared by mistake. Your street address is a good example. The never-write
# list is a short list of words like that. Before any file is saved, the
# privacy guard is set up to check it for those words and stop if it finds
# one. The list itself is set up to stay on your computer. What you put in it
# is up to you.
#
# What doesn't belong anywhere. Some information is too sensitive for any of
# this. It's a good idea never to share information like passwords, PINs,
# credit or debit card numbers, or bank account numbers with an AI tool, and
# never to put it anywhere in this system, not even in the never-write list or
# the private folder.
#
# How to write entries: one per line. Lines that start with # are comments.
# Matching ignores upper and lower case. Use entries of at least 4
# characters, so the guards don't block ordinary words.
#
# To test the list, add a made-up word on its own line (the Guide makes one
# up for you), ask your AI to try writing it into a file, then delete the test
# word. Always test with a made-up word, never with something real.
#
